シームレス地質図データを使う

ベクトル形式データのダウンロード

20万分の1日本シームレス地質図V2のベクトル形式の地質図データをダウンロードしてご利用いただけます．利用規約等につきましては「ご利用にあたって」のページをご確認ください．

  • 凡例はこちら

    シームレス地質図V2の凡例

  • 全国一括ダウンロード（シェープファイル）

    seamlessV2.zip（ZIP形式, 238MB, 地質図更新日：2025年7月18日）

  • 20万分の1地図区画毎のダウンロード（シェープファイル, KMLファイル）

ラスター形式データのダウンロード

シームレス地質図V2のラスター形式ファイルにつきましてはシームレス地質図V2 ビューアでファイル（PNG，KMZ，HTML）に出力する機能を提供しております．ビューアの左上に表示されているツールボタンの［その他の操作］→［表示画面の保存］からご利用ください．

Web APIの利用

皆様のWebサイトやアプリケーションから自由にアクセスし，地質図や凡例が利用できるWeb APIを公開しています．

  • Web APIのご利用はこちら：

    20万分の1日本シームレス地質図V2 Web API （ver 1.3.1, 2023/10/6）

  • ［更新内容］typeパラメータで指定可能な値にlevel4(凡例数 約400)を追加
  • ［旧バージョン］
    • ver 1.3（2022/9/9） typeパラメータを追加，地質図取得サービスにbase, opacity, lang, downloadパラメータを追加
    • ver 1.2.1（2020/6/9） 凡例取得サービスjsonフォーマットにtitleとvalueを追加
    • ver 1.2（2018/5/18）地質図取得サービスにlayerパラメータを追加
    • ver 1.1（2018/4/27）凡例取得サービスの出力ファイルフォーマットにhtml形式を追加
    • ver 1.0（2018/3/11）
